# LCProp 0.5.0rc1

Engine-first prerelease for scalar optical beam propagation in liquid-crystal
(LC) and photorefractive (PR) media. The optional Colab preview has separate
LC static and reduced nonlinear PR TD notebooks.

## Install the engine

Use the wheel from this staging set for review. After publication, obtain
the wheel and `SHA256SUMS` from the same release assets. The staged
`lcprop-0.5.0rc1-py3-none-any.whl` has SHA-256:

`19ebc9625ac8de9ef184729f0da3a1cb68e90d1ae194dce4db29bab6a9143b69`

Compare the output to that value before installing. Use `sha256sum` on
Linux or `shasum -a 256` on macOS. From a clean Python 3.12 environment:

```sh
shasum -a 256 lcprop-0.5.0rc1-py3-none-any.whl
python3.12 -m venv .lcprop-engine
.lcprop-engine/bin/python -m pip install ./lcprop-0.5.0rc1-py3-none-any.whl
.lcprop-engine/bin/python -m pip check
```

The core requires Python 3.10 or newer. Qt, LaunchPlane and notebook
dependencies are optional for their respective interfaces.

## Colab preview

Use the pinned [LC notebook](../../notebooks/lcprop_lc_colab.ipynb) or
[PR notebook](../../notebooks/lcprop_pr_colab.ipynb) from the same staging
set. Verify their hashes against the artifact manifest and follow the
[Colab setup and file guide](../colab_first_batch.md). Both start on CPU
by default. LC is CPU-only. PR can explicitly opt in to a Colab T4 before
creating the controller.

Use Colab's native picker for reopen, the Files pane for ZIP download
if needed, and **Refresh status** if browser progress lags. Direct
browser download remains unqualified. Narrow panes can clip the colorbar.
Saved LC result acceptance and fuller desktop parity remain deferred.

## Qualification scope

The earlier qualified Batch 4 wheel had SHA-256
`b282fa09896a69353edf717e7bf238924e0c0c666a2cd7b1ffc87800aaeab28c`.
The staged rebuild changes wheel documentation metadata. Its executable
payload and dependency declarations are unchanged.

- Hosted fake-runner checks on the qualified wheel exercised PR CPU default
  and explicit T4 opt-in. The T4 probe used real hardware. The fake runners
  performed no propagation.
- Real runs on the qualified wheel compared the frozen three-step 20 µm
  and 1 mm PR fixtures on CPU and T4. All six compared quantities passed
  for each fixture. A separate 1 mm T4 run acknowledged Stop during
  computation and preserved the prior result. Colab CPU reopened the
  saved GPU ZIP through the native picker and re-exported it byte-for-byte.
- The hosted qualification used Python 3.13, NumPy 2.4.6 and SciPy 1.16.3.
  The recorded T4 environment used CUDA 13.0 with CuPy 14.0.1
  (`cupy-cuda13x`). Qualification does not extend to the optional CUDA 12
  extra, other GPU workloads or a performance advantage.
- A fresh hosted setup smoke test of the rebuilt wheel and both final
  notebook files is pending. The retained numerical evidence identifies
  the earlier wheel by its own checksum.
