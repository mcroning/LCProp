# LCProp 0.5.0rc1

Engine-first prerelease for scalar optical beam propagation in LC and PR media.
The optional Colab interface is a bounded CPU preview. Desktop GUI and GPU
qualification are separate.

Download `lcprop-0.5.0rc1-py3-none-any.whl` from the release assets once
available. Expected SHA-256:

`e54a24d1927583a37d49ea1df90fa08e1db09438d3309052166c87858f835c0d`

In a new directory, verify the downloaded wheel and install into a clean
Python 3.12 environment. Use `sha256sum` on Linux or `shasum -a 256` on macOS.

```sh
shasum -a 256 lcprop-0.5.0rc1-py3-none-any.whl
python3.12 -m venv .lcprop-engine
.lcprop-engine/bin/python -m pip install ./lcprop-0.5.0rc1-py3-none-any.whl
.lcprop-engine/bin/python -m pip check
```

Compare the hash before installing. Core installation does not require Qt,
LaunchPlane or notebook dependencies.

The code baseline is `c83b3c529313b1153b9443f8f8fa1fd760c7eb5d`, with a
release documentation patch. The baseline recorded 36 focused checks and a
fresh Colab CPU install that reopened a saved three-step PR result. The earlier wheel also passed hosted ZIP reopen. A subsequent
beam editor fix replaces the collapsed accordion with visible controls.
Hosted acceptance of the wheel identified above is pending.

Open the [pinned notebook](../../notebooks/colab_first_batch.ipynb) and follow
the [Colab guide](../colab_first_batch.md). Use the native picker to reopen
files and **Refresh status** if background updates lag. For completed export,
the guide provides a Files-pane workaround. Browser download remains
unverified.
