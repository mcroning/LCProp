# LCProp 0.5.0rc2

Engine prerelease with the optional LC and PR Colab notebooks. This
candidate includes the PR notebook results fixes merged in pull request
#11. Completed volume views expose the longitudinal cut selector,
space-charge fields have distinct names, and narrow panes can scroll
to reach the plot edges. Wide Physical XZ and YZ views place the
colorbar beneath the image.

## Install the engine

Use the wheel and SHA256SUMS from the candidate bundle during review.
After publication, use the [GitHub prerelease assets](https://github.com/mcroning/LCProp/releases/tag/v0.5.0rc2).
Verify the wheel against the matching manifest before installing.

```sh
shasum -a 256 -c SHA256SUMS
python3.12 -m venv .lcprop-engine
.lcprop-engine/bin/python -m pip install ./lcprop-0.5.0rc2-py3-none-any.whl
.lcprop-engine/bin/python -m pip check
```

The core requires Python 3.10 or newer. The notebook and desktop
interfaces have optional dependencies.

## Colab preview

Use the pinned LC or PR notebook from the same bundle, and follow the
[Colab setup and file guide](../colab_first_batch.md). Both start on CPU.
LC is CPU-only. PR can explicitly opt in to a Colab T4 before creating
the controller. Use the native picker to reopen saved results and the
Files pane to download an exported ZIP if direct download is unavailable.

## Colab CPU acceptance

Both pinned notebooks passed fresh Colab CPU installation, kernel
restart, exact-wheel verification and interface startup. The PR notebook
reopened a saved 1 mm result through Colab's native file picker at three
of three completed steps. All nine re-exported files matched the
original SHA-256 checksums, and no extraction directories remained.

With the Files pane open, the Physical XZ intensity plot scrolled in
both directions. At the right edge, the 1,000 µm tick and full horizontal
colorbar were visible. This check used saved results. Earlier hosted
CPU and T4 qualification is documented in the [rc1 release notes](0.5.0rc1.md).
