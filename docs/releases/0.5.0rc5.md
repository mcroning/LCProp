## Open in Colab

1. Open the candidate notebook and connect to a CPU runtime.
2. Upload the matching setup ZIP through Colab's Files sidebar, keeping it zipped.
3. Run Open PR workbench. If requested, restart the session once and rerun the same cell.

The opener verifies the ZIP and inner wheel before installation. Drive is optional
and not needed to open. Only Run starts propagation. Inspect synthetic or existing
saved data through Files; use Refresh workbench files inside the workbench after
sidebar uploads, then Saved file and Open selected file.

Rerunning Open reconnects to an existing live controller; save drafts/results before
replacing or deleting a runtime. Notebook autosave does not preserve result arrays.
