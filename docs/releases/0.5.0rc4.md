# LCProp 0.5.0rc4 candidate — reduced PR workbench

Unpublished CPU-first candidate for the simplified reduced x-only PR Static and
time-dependent workbench. This release adds the single Open cell, independently
sampled beam-editing preview, visible Run-blocker explanations, and saved-file
controls. Advanced settings and diagnostics remain available but collapsed.
LC remains separate. Desktop instructions and published rc1/rc2/rc3 assets are
unchanged; the public README continues to point to rc3 until rc4 is published.

## Required files

For review, obtain these five files from the same candidate delivery. After a
separately approved publication, they must all be GitHub prerelease assets:

- `lcprop-0.5.0rc4-py3-none-any.whl`
- `LCProp-PR-workbench-0.5.0rc4-candidate.ipynb`
- **`LCProp-PR-workbench-setup.zip` — required for fresh Colab opening**

- `SHA256SUMS`

The setup ZIP contains the exact wheel. Keep it zipped; the notebook verifies
both the ZIP and inner wheel automatically. No separate wheel upload is needed.

its setup ZIP automatically and does not need Google Drive access.

The proposed flat release manifest is [SHA256SUMS](0.5.0rc4/SHA256SUMS).
It covers the four payload files above, placed beside it in one directory:

```sh

```

This new flat manifest describes the proposed release layout. The original
verified staging manifest, which uses `artifacts/` and `delivery/` paths, remains
unchanged and must be checked from its original staging root instead.
There is no rc4 release URL yet; do not substitute rc3 files or change its links.

## Open the PR workbench in Colab

1. Open `LCProp-PR-workbench-0.5.0rc4-candidate.ipynb` in Colab and connect to a
   **CPU** runtime.
2. Use the Files sidebar → Upload to upload **LCProp-PR-workbench-setup.zip**.
   Keep it zipped. Do not choose a result ZIP or a separate wheel for setup.
3. Run **Open PR workbench**. If asked, choose **Runtime → Restart session** once
   and rerun that same cell. Then use **Beams / Results / Files**.

Only the workbench's Run button starts propagation. To inspect without running,
choose **Files → Open synthetic example**, or upload a saved experiment JSON or
completed-result ZIP through the sidebar, choose **Refresh file list**, select
that file, then **Open selected file**. The synthetic example is display data,
not a scientific result. Ordinary and uppercase JSON filenames are supported.

After a browser disconnect, rerun Open to redisplay the same live controller and
preserve committed drafts/results. Deleting or replacing the runtime loses unsaved
state; notebook autosave does not save result arrays. Save needed files first.
If setup fails, read its explanation and rerun the same cell after resolving the
reported prerequisite. Do not change scientific settings to repair installation.

## Optional core-only installation

Colab setup installs notebook dependencies in its disposable runtime, including
Matplotlib 3.11.2 for widget compatibility. For engine-only use, verify the files
first and install the exact wheel into a new environment, separate from desktop:

```sh
python3 -m venv .lcprop-rc4-core
.lcprop-rc4-core/bin/python -m pip install ./lcprop-0.5.0rc4-py3-none-any.whl
.lcprop-rc4-core/bin/python -m pip check
```

Python 3.10 or newer is required. These commands are installation instructions;
this candidate's actual core import check used an isolated target and existing
core dependencies, as qualified in the acceptance summary.

## Scope and limits

Reduced x-only PR Static and time-dependent evolution, existing beam/material/grid/
solver controls, and available saved fields and XY/XZ/YZ plots are included.
Optical XY images do not imply full-transverse material diffusion/transport.
CPU is default. Inherited Auto/GPU choices retain existing library guards; this
CPU opening flow installs no CUDA software and grants no new GPU qualification.
Full-transverse PR, LC interface changes and private split-backup tools are excluded.

Limits remain 256 MiB per result, 2.5 GiB working plus resident results, 512 MiB
runtime reserve, 60-second cooperative PR budget, and 128 MiB ZIP import/export.
Sampling and available-memory validation can block Run; the reason appears beside
it. The independently sampled editing preview does not relax scientific validation.
Stop/time limits are cooperative. Static convergence and TD completion are distinct.
Optional Drive storage is not mounted merely by opening the workbench; no fresh
rc4 Drive acceptance or broader scientific qualification is claimed.
