# LCProp 0.5.0rc3 candidate

CPU-first engine and Colab prerelease candidate. The LC notebook offers static
and time-dependent propagation. The PR notebook offers reduced x-only static
and time-dependent propagation. The workflows have separate drafts and
results, editable grids and solver settings, and request inspection.

The notebook checks memory before admitting work and applies separate ZIP
limits. Supported results can be reopened or exported, with optional verified
Google Drive copies. LC time-dependent completed ZIP export, continuation and
full-transverse PR remain outside this candidate. Both candidate notebooks use
CPU. The reduced PR Static solver now resolves physical illumination from the
accepted launch and validates its metadata during result transport.

## Install and verify

Obtain the wheel, both notebooks and SHA256SUMS from the same candidate
bundle. After publication, obtain them from the GitHub prerelease assets.

```sh
shasum -a 256 -c SHA256SUMS
python3.12 -m venv .lcprop-engine
.lcprop-engine/bin/python -m pip install ./lcprop-0.5.0rc3-py3-none-any.whl
.lcprop-engine/bin/python -m pip check
```

For Colab review, open the LC or PR notebook in a fresh CPU session and upload
the candidate wheel to session storage. Run setup, restart the session, then
run Verify installation and open the interface. Once the release asset exists,
setup downloads the pinned wheel automatically when it is absent.
